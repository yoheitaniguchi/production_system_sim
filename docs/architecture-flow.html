production_system_sim アーキテクチャフロー可視化

アプリ内の package（ディレクトリ／モジュール単位）と component（ファイル・関数単位）の間を、 主要な操作（アクション）がどう伝播するかを可視化した単一ページHTMLです。

下のボタンでアクションを選ぶと、そのアクションが完了するまでに通る package / component が ハイライトされ、間で渡されるデータが注釈として表示されます。 この画面は、ページ下部に埋め込まれた JSON（<script type="application/json" id="flow-data">）を元に描画されています。

本シミュレータは7ドメイン（受注・計画・発注・工程・在庫・出荷・マスタ）＋分析系タブ（KPI・原価・ペギング追跡・ ロット追跡・演習ガイド・プロセス連携図）を持つため、姉妹リポジトリmini-simulatorより扱う操作の種類が多い。 ここでは全操作を網羅せず、MRP展開からペギング・バックフラッシュ・ロット系譜まで、v5仕様書の中核である 受注〜出荷の一連の流れを代表的な操作として選んでいる（全操作の一覧は docs/design.md §7 参照）。

発想の元ネタ： 「Claude Codeでアプリの処理フローをHTML＋JSONで可視化させる発想がかなり実務的だった」（Qiita） で紹介されていたプロンプトを、このリポジトリのソースコード（src/App.tsx・src/domain/reducer.ts・ src/domain/*.ts ほか）を実際に読んだ上で再現したものです。推測で埋めた箇所はありません。 姉妹リポジトリmini-simulatorの docs/architecture-flow.html（同じ発想で先に作成済み）と 同じ構成のページを、本リポジトリのドメイン・アクション体系に合わせて作り直しています。
