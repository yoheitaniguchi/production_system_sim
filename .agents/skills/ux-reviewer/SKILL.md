# UX Reviewer Skill

このスキルは、`src/components/` 配下の画面実装（`components/*.tsx`, `components/master/*.tsx`）をUI/UXおよび教材としての使いやすさの観点からレビューする際に使用します。

## 主なレビュー観点

1. **情報設計 & タブ構成**:
   - 3層（共通シェル／ドメイン画面／分析画面）の役割分担が直感的に伝わっているか。
   - 関連画面（ペギング追跡とロット追跡、KPIと原価など）の違いが明確か。
2. **操作導線**:
   - `AlertBar` や `TodayActionsBar` から該当操作画面へのスムーズな遷移があるか。
   - 破壊的操作（リセット、マスタ一括削除・インポート）の確認ダイアログが適切か。
3. **メッセージ & フィードバック**:
   - 空状態やバリデーションエラー時に「次に何をすべきか」が具体的に示されているか。
   - ボタンの disabled 理由が明示されているか。
4. **UIの一貫性 & アクセシビリティ**:
   - プライマリボタンのスタイル、ステータスラベルの日本語化、用語の統一。
   - 色だけに依存しない状態表示、キーボード・スクリーンリーダー対応。
